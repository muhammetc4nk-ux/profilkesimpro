PROFIL KESIM PRO - Android Studio projesi

1. Android Studio'da Open > ProfilKesimPro klasorunu secin.
2. Gradle senkronizasyonunu bekleyin (internet gerekir).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK: app/build/outputs/apk/debug/app-debug.apk
5. APK'yi Android telefona aktarip kurun.

Not: Kaynak uygulamanin fotoğraftan otomatik metin okuma ozelligi garanti edilmez. Dosya secimi desteklenir. Android WebView icinde JSON indirme ve yazdirma islevleri ek yerel kod gerektirebilir. Bu kaynak kodu APK degildir.
